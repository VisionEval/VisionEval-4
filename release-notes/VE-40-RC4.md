This minor release updates the installer (consistent with the website) to work smoothly in all variations. The website has the current installer scripts.

This release also updates the prohibition on  "AutoMeanAge" and "LtTrkMeanAge" in VEHouseholdVehicles so mean age up to 25 years is allowed.

To use it, I'd suggest a fresh VE installation. It should work with any recent VE however. To get the update, you can install the win.library version of this release into a new "VE_HOME" folder, and then copy the VEHouseholdVehicles folder from the new VE_HOME ve-lib/X.Y (X.Y = your R version major.minor) to your "real" VE_HOME/ve-lib/X.Y, overwriting what was there.
